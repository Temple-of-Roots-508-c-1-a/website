# website

Public site for Temple of Roots — GitHub Pages from this repo (`templeofroots.com`).

## Layout

- `*.html` — pages at site root
- `assets/` — CSS, JS, and images **used by the live site** (copy logo from `../assets/canva/` when brand updates)
- `forms/` — public forms
- `web3/` — public ENS / web3 info
